# Deck Patterns

Use these patterns as starting points. Adapt slide count to the user's material and audience.

## Weekly Update

Best for: casual update with a boss, team sync, project pulse.

Structure:

1. This week's headline
2. Progress since last update
3. Evidence: metrics, artifacts, shipped work, customer signal
4. Risks or blockers
5. Decisions needed
6. Next week's focus

Design:

- concise, scannable, operational
- one status color system only: on track, watch, blocked
- small proof screenshots or metric chips are useful
- cute art should be subtle: small stickers, divider motif, friendly empty states

## Work Story

Best for: persuading a manager, explaining a project, summarizing a proposal.

Structure:

1. Situation and why now
2. Tension or opportunity
3. Core insight
4. Options considered
5. Recommended path
6. Execution plan
7. Ask or decision

Design:

- use diagrams, timelines, and before/after comparisons
- make tradeoffs visible
- avoid generic strategy icons

## Resume Or Portfolio Deck

Best for: job search, internal mobility, personal brand, project portfolio.

Structure:

1. Positioning statement
2. Snapshot: roles, strengths, domains
3. Signature wins
4. Case study 1: problem, action, result
5. Case study 2: problem, action, result
6. Working style and values
7. Role fit or next chapter

Design:

- polished, editorial, confident
- use measured personal warmth
- quantify impact wherever possible
- cute art can work as an original personal motif, not as decoration on every slide

## Storytelling Or Explainer

Best for: teaching, lightweight narrative, casual presentation, creative pitch.

Structure:

1. Hook
2. Character, audience, or user
3. Problem
4. Journey or mechanism
5. Example
6. Payoff
7. Takeaway

Design:

- use visual continuity across slides
- repeat a character, map, object, or scene element
- use fewer words and stronger images

## Executive Or Leadership Narrative

Best for: leadership update, board-style story, strategic recommendation.

Structure:

1. Executive thesis
2. External or internal shift
3. Evidence
4. Strategic choice
5. Operating implications
6. Roadmap and milestones
7. Risks, mitigations, and asks

Design:

- restrained, information-rich, precise
- prefer charts, tables, operating maps, and proof artifacts
- cute art should be used only if the user explicitly wants a warmer tone
