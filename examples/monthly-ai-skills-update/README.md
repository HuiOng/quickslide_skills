# Monthly AI Skills Update

This example is a static HTML slide deck generated with `slide-storyteller`.

Prompt summary:

```text
Create an HTML slide for a monthly update to my manager about exploring AI to create skills,
build agents, produce mockups, define reusable standards, plan with AI before building,
and connect PRDs to user stories and engineering handoff mockups.
```

Files:

- `index.html`: self-contained HTML slide deck
- `previews/slide-01.png`: screenshot of the opening slide

Design direction:

- summer garden professional
- light canvas
- sage and leaf green structure
- pale sky, sunlight, and petal accents
- manager-friendly monthly update narrative
