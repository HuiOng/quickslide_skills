# Repository Instructions

This workspace contains a local Codex skill for creating polished presentation decks.

## Project Shape

- `slide-storyteller/SKILL.md` is the main skill instruction file.
- `slide-storyteller/references/` contains focused guidance that Codex should read only when relevant.
- `slide-storyteller/agents/openai.yaml` contains UI metadata for the skill.

## Working Rules

- Keep the skill concise and practical.
- Prefer references for reusable deck patterns, art direction, and examples.
- Do not add broad README-style documentation unless the user asks for it.
- Validate skill changes with the Skill Creator quick validator before considering the work complete.
